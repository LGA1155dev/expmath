## 📖 Sobre o projeto

O **ExpMath** é uma aplicação web educacional desenvolvida com o objetivo de auxiliar estudantes na revisão e prática de conteúdos relacionados às funções exponenciais.

O projeto foi criado pensando na necessidade de praticar matemática de uma maneira mais interativa, especialmente durante a preparação para provas e avaliações escolares.

A proposta é utilizar um formato de quiz para transformar a revisão de conteúdo em uma experiência mais dinâmica, permitindo que o estudante teste seus conhecimentos e exercite o raciocínio matemático.

Em vez de apenas revisar fórmulas ou reler anotações, o usuário pode participar de uma atividade prática, respondendo questões relacionadas ao conteúdo estudado.

---

## 🎯 O problema

Durante a preparação para provas de matemática, muitos estudantes enfrentam dificuldades para revisar conteúdos e testar se realmente compreenderam a matéria.

Algumas dificuldades comuns são:

- 📚 Revisar grandes quantidades de conteúdo em pouco tempo.
- 🧠 Memorizar fórmulas sem compreender sua aplicação.
- 📝 Encontrar maneiras práticas de testar o próprio conhecimento.
- 😴 Perder o interesse durante métodos tradicionais de revisão.
- ❓ Não saber quais conceitos ainda precisam de mais atenção.

Apenas ler o conteúdo nem sempre é suficiente para identificar se o estudante realmente consegue aplicar aquilo que aprendeu.

É necessário praticar, responder questões e exercitar o raciocínio.

---

## 💡 A solução

O ExpMath propõe uma forma mais prática de revisar funções exponenciais por meio de um quiz interativo.

A ideia é transformar o conteúdo estudado em desafios, permitindo que o estudante coloque seus conhecimentos em prática e tenha uma experiência de revisão mais ativa.

A aplicação funciona como uma ferramenta complementar de estudo, oferecendo uma maneira rápida e acessível de praticar matemática diretamente pelo navegador.

### 🧮 Por que um quiz?

Quizzes educacionais permitem que o estudante:

- 🎯 Teste o próprio conhecimento.
- 🧠 Exercite o raciocínio.
- 🔄 Reforce conteúdos já estudados.
- 📌 Identifique dúvidas e dificuldades.
- ⚡ Pratique de maneira rápida e objetiva.

O objetivo não é substituir aulas ou materiais didáticos, mas oferecer uma alternativa de prática para ajudar na preparação escolar.

---

## 📐 Conteúdo abordado

O projeto tem como foco as **funções exponenciais**, um conteúdo matemático que envolve potências, relações entre variáveis e comportamentos de crescimento ou decrescimento.

O estudo de funções exponenciais é importante para compreender diferentes fenômenos matemáticos e aplicações em áreas como matemática financeira, biologia, física e outras disciplinas.

Entre os conceitos relacionados ao tema estão:

- 🔢 Potenciação.
- 📈 Crescimento exponencial.
- 📉 Decrescimento exponencial.
- 🧮 Propriedades das potências.
- 📊 Comportamento de funções exponenciais.
- 📝 Interpretação e resolução de exercícios.

## ⚙️ Como funciona?

O ExpMath foi desenvolvido para permitir que o estudante acesse a aplicação e pratique o conteúdo por meio de questões.

O fluxo de utilização consiste em:

1. 🌐 Acessar a aplicação pelo navegador.
2. 📚 Iniciar a atividade de revisão.
3. 🧮 Resolver as questões sobre funções exponenciais.
4. 🎯 Selecionar ou informar as respostas de acordo com o quiz.
5. 🧠 Utilizar a prática como reforço do conteúdo estudado.

A proposta é proporcionar uma experiência simples, permitindo que o usuário se concentre na matemática e na resolução dos desafios.

## 🚀 Como executar localmente

Você pode clonar o projeto e executar localmente para visualizar, estudar ou realizar modificações.

### 1️⃣ Clone o repositório

```bash
git clone https://github.com/LGA1155dev/expmath.git
```

### 2️⃣ Entre na pasta

```bash
cd expmath
```

### 3️⃣ Execute o projeto

Como a aplicação possui sua estrutura concentrada em HTML, você pode abrir o arquivo `index.html` diretamente no navegador.

Ou utilize um servidor local com Python:

```bash
python3 -m http.server 8000
```

### 4️⃣ Acesse no navegador

```text
http://localhost:8000
```
